# Movie Recommendation System

A content-based movie recommendation system that uses Natural Language Processing (NLP) and movie metadata to recommend similar movies.

## Dataset

The dataset files (`df.pkl` and CSV) are hosted on Google Drive.

[Access Dataset Files](https://drive.google.com/drive/folders/1HQTebFi9DieyJsUNMDRDfSskGbz2n4g_?usp=drive_link)

## Project Workflow

- Data Cleaning
- Data Preprocessing
- NLP & Text Processing
- Feature Engineering
- Text Vectorization
- Feature Combination
- Similarity Calculation
- Movie Recommendation

## NLP Techniques

- Text preprocessing
- Feature extraction from movie metadata
- Text vectorization
- Content-based similarity

## Recommendation Approach

The system combines relevant movie information such as genres, keywords, overview, cast, and other metadata to create a content representation of each movie.

NLP-based feature extraction is then used to calculate similarity between movies and generate recommendations.

## Technologies

Python, Pandas, NumPy, Scikit-learn, NLP, Jupyter Notebook
