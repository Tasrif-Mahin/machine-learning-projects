# Sentiment Analysis

A Natural Language Processing (NLP) machine learning project for classifying text based on sentiment.

## Project Workflow

- Data Cleaning
- Text Preprocessing
- Exploratory Data Analysis
- NLP & Feature Engineering
- Text Vectorization
- Model Training
- Model Comparison
- Model Evaluation

## NLP Techniques

- Text Cleaning
- Tokenization
- Stopword Removal
- Text Vectorization
- Feature Extraction

## Models

- Logistic Regression
- Naive Bayes
- Support Vector Machine

## Technologies

Python, Pandas, NumPy, Scikit-learn, NLTK, Matplotlib, Jupyter Notebook
