# Heart Rate Analysis

A machine learning application for analyzing heart rate data, with an interactive user interface for exploring data and generating predictions.

## Project Workflow

- Data Cleaning
- Exploratory Data Analysis
- Feature Engineering
- Data Preprocessing
- Model Training
- Model Evaluation
- Prediction
- Interactive UI

## Features

- Heart rate data analysis
- Data visualization
- Machine learning prediction
- Interactive user interface
- User input for predictions

## Project Structure

- `heart_rate.ipynb` - Data analysis, feature engineering, model development, and evaluation
- `model.pkl` - Trained machine learning model
- `app.py` - Application and user interface
- Other Python files - Supporting application code

## Technologies

Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Jupyter Notebook

## Application

The project includes an interactive UI that allows users to provide input data and use the trained machine learning model to generate predictions.
