# Titanic Survival Prediction

A machine learning classification project for predicting passenger survival using demographic and passenger information from the Titanic dataset.

## Project Workflow

- Data Cleaning
- Exploratory Data Analysis
- Data Preprocessing
- Feature Engineering
- Feature Encoding
- Model Training
- Model Comparison
- Model Evaluation

## Models

- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier

## Technologies

Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Jupyter Notebook
