
# Iris Classification

A machine learning classification project for predicting Iris flower species based on flower measurements.

## Project Workflow

- Data Loading
- Exploratory Data Analysis
- Data Visualization
- Data Preprocessing
- Feature Analysis
- Model Training
- Model Comparison
- Model Evaluation

## Models

- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier

## Technologies

Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Jupyter Notebook
