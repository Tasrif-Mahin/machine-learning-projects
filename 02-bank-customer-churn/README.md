# Bank Customer Churn Prediction

Machine learning project for predicting whether a bank customer is likely to churn based on customer characteristics and account information.

## Project Workflow

- Data Cleaning
- Exploratory Data Analysis
- Feature Engineering
- Data Preprocessing
- Model Training
- Model Comparison
- Model Evaluation

## Models

- Logistic Regression
- Random Forest
- Gradient Boosting
- AdaBoost
- Support Vector Classifier

## Technologies

Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn
