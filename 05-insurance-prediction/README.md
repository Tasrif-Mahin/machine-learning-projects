# Insurance Prediction

A machine learning project for predicting insurance-related outcomes using customer and demographic features.

## Project Workflow

- Data Cleaning
- Exploratory Data Analysis
- Data Preprocessing
- Feature Engineering
- Model Training
- Model Comparison
- Model Evaluation

## Models

- Logistic Regression
- Decision Tree
- Random Forest
- Gradient Boosting
- AdaBoost

## Technologies

Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Jupyter Notebook
