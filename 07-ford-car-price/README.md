# Ford Car Price Prediction

A machine learning regression project for predicting Ford car prices based on vehicle features.

## Project Workflow

- Data Cleaning
- Exploratory Data Analysis
- Data Preprocessing
- Feature Engineering
- Model Training
- Model Comparison
- Model Evaluation

## Models

- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor
- XGBoost Regressor

## Technologies

Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, XGBoost, Jupyter Notebook
