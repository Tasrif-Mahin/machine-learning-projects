# Demand Forecasting

An end-to-end machine learning project for predicting product demand using historical sales data.

## Overview

This project focuses on predicting future product demand using historical data and machine learning regression models.

The project includes data preprocessing, exploratory data analysis, feature engineering, model training, model comparison, and evaluation.
